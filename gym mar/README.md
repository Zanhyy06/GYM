# GymSmart

Prototipo premium de interfaz para una plataforma de gestión deportiva orientada a:

- rutinas personalizadas;
- control de asistencia y alertas de permanencia;
- estadísticas de actividad;
- visibilidad de proyectos de investigación.

## Ejecutar

Abrir `index.html` directamente en el navegador o iniciar un servidor local:

```powers
cd "ruta/al/proyecto"
python -m http.server 8080
```

Después, visitar `http://localhost:8080`.

## Alcance visual

Esta versión prioriza diseño UI/UX y navegación con datos demostrativos. No incluye autenticación real, persistencia ni backend.

## Archivos

- `index.html`: estructura de la aplicación.
- `styles.css`: sistema visual, componentes y responsive.
- `app.js`: navegación, vistas y acciones simuladas.

## Tecnologías

HTML5, CSS3 y JavaScript vanilla. Los iconos usan Lucide y las imágenes se cargan desde Unsplash.
